# API de Gerenciamento de Categoria

Serviço RESTful criado com **Spring Boot** para gerenciar os dados de Categorias. O projeto exercita a construção de uma estrutura em camadas (Model, Repository, Service, Controller) e o mapeamento JPA com múltiplos campos de texto.

## 🚀 Tecnologias Utilizadas
* Java
* Spring Boot
* Spring Data JPA
* Banco de Dados Relacional

## 📌 Endpoints da API

A API expõe os seguintes endpoints na rota base `/Categorias`:

* `POST /Categorias`: Cria um novo Categoria.
* `GET /Categorias`: Lista todos os Categorias cadastrados.
* `GET /Categorias/{id}`: Busca um Categoria específico pelo seu ID.
* `DELETE /Categorias/{id}`: Deleta um Categoria específico pelo seu ID.
